# Curio Box 标签系统与高级检索语法指南

Curio Box 采用了受到工业级数字资产管理（如 Danbooru、Hydrus Network）启发的**正交命名空间标签体系（Namespaced Tagging System）**与**声明式检索 DSL**。

本指南旨在说明如何规范地组织标本工件、运用高级语法快速检索，以及在镜像暗房中与大模型协同维护标签。

---

## 一、 标签结构与命名规范

Curio Box 的每个工件可挂载多枚标签，标签分为**正交命名空间标签**与**自由平铺标签**：

### 1. 命名空间标签 (推荐)
格式为 `命名空间:具体属性`（全部采用半角冒号 `:` 分隔，英文小写或中文规范）：

| 命名空间 | 语义定义 | 典型示例 |
| :--- | :--- | :--- |
| `形态:` | 渲染图元或底层技术栈 | `形态:webgl`、`形态:canvas`、`形态:threejs`、`形态:原生html` |
| `物理:` | 数理模型与力学模拟机制 | `物理:粒子`、`物理:流体`、`物理:引力`、`物理:弹簧摆` |
| `领域:` | 学科或艺术分类 | `领域:图形学`、`领域:生成艺术`、`领域:数学可视化` |
| `状态:` | 工件的生命周期与策展状态 | `状态:新建`、`状态:精选`、`状态:未分类` |
| `模型:` | 生成该工件的大模型基座 | `模型:claude-3.5-sonnet`、`模型:gpt-4o` |

> **设计优势**：命名空间天然避免标签碎片化，使得“webgl”与“流体”在不同的认知维度正交解耦，同时便于按维度快速切片检索。

### 2. 自由平铺标签
不包含冒号的自由词汇，如 `cyberpunk`、`霓虹`、`极简`。主要用于风格、情绪等偶发性非结构化描述。

## 二、 检索 DSL 语法速查

顶部导航栏的聚合搜索框（快捷键 `⌘K` / `Ctrl+K`）支持全功能检索 DSL：

### 1. 基础交集 (AND) 与排除 (NOT)
* **空格分隔（交集 AND）**：
  ```
  形态:webgl 物理:流体
  ```
  *说明：筛选同时具有两个标签的工件。*

* **`-` 负向排除（补集 NOT）**：
  ```
  形态:webgl -物理:粒子
  ```
  *说明：筛选 WebGL 工件，但剔除包含粒子特性的标本。*

---

### 2. Glob 通配符查询 (`*` / `?`)
在标签名或值中使用 `*`（匹配任意长度字符串）或 `?`（匹配单个字符）：

* **按命名空间通配过滤**：
  ```
  形态:*
  ```
  *说明：匹配所有标注了任意形态的工件。*

* **批量通配排除**：
  ```
  -模型:* 或 -model:*
  ```
  *说明：排除所有标注了大模型来源的工件，仅保留纯自主编写的标本。*

* **跨命名空间模糊匹配**：
  ```
  *流体*
  ```
  *说明：无论在“物理:流体”还是在“领域:流体仿真”，只要包含“流体”字样均被命中。*

---

### 3. 多值并集联合 (OR 管道符 `|`)
无需重复键入命名空间前缀，通过 `|` 分隔候选项：

* **命名空间内多选（推荐）**：
  ```
  形态:webgl|canvas|threejs
  ```
  *说明：筛选形态是 WebGL、Canvas 或 Three.js 任意之一的工件。*

* **复合组合**：
  ```
  形态:webgl|canvas 物理:流体|引力 -状态:未分类
  ```
  *说明：`(WebGL 或 Canvas) AND (流体 或 引力) AND (非未分类)`。*

---

### 4. 内置属性与数值范围断言 (Range Predicates)
无需切换鼠标点击顶部按钮，直接在搜索框敲入属性断言表达式：

| 属性语法 | 语义与别名 | 说明与示例 |
| :--- | :--- | :--- |
| `rating>=4` | `star>=4`、`星级:>=4`、`评分:>=4` | 筛选 4 星及以上的高分精选标本 |
| `rating:5` | `star:5`、`星级:5` | 仅筛选满分 5 星工件 |
| `rating:3..5` | 连续闭区间范围 | 筛选评分在 3 星至 5 星之间的工件 |
| `rev>1` | `revision>1`、`版本:>1` | 筛选经历过多次版本迭代的标本（排除 REV:1 初始版本） |
| `has:poster` | `has:封面` | 仅筛选已定格封面海报的工件 |
| `-has:poster` | 否定断言 | 仅筛选**未定格封面**的工件（等价于“待定格”快捷胶囊） |

#### 典型组合查询示例：
```
形态:webgl|threejs rating>=4 -has:poster
```
> **含义**：快速定位**“评级为 4 星以上、使用 WebGL 或 Three.js 技术、但尚未定格封面”**的工件，便于集中抓取封面。

## 三、 键盘流与自动补全体验

### 1. 全局搜索框交互
1. 按下 **`⌘K`** (macOS) 或 **`Ctrl+K`** (Windows/Linux) 直接聚焦顶栏搜索框。
2. 输入 `r` 或 `星`，补全列表首部自动浮现系统宏谓词（如 `rating:>=4`、`has:poster`）。
3. 使用 **`↑` / `↓`** 键在候选浮层中高亮目标，按下 **`Enter`** 即可选定上屏。
4. 输入 `形态:webgl|` 并敲入下一个首字母时，系统能感知管道符边界，并提供当前命名空间下的后续多选值。

### 2. 标本档案抽屉中的打标签模式
在档案检视抽屉（Inspector）中：
* 输入框会自动切换为**纯标注模式**，自动隐藏所有查询断言（不会误推 `rating:>=4` 等非标签内容）。
* 输入命名空间后回车或点击，自动保留焦点，支持一路无缝连续键入与选定。

## 四、 智能画册 (Smart Albums) 联动

智能画册的核心即为本套 Tag Query DSL。在创建智能画册时，只需设定其规则：

```
形态:webgl 物理:流体 rating>=4
```

* **自适应动态收录**：今后任意新建、导入或更新的工件，只要符合该表达式，都会**自动入册**。
* **脱机策展放映**：智能画册可一键打包导出为自包含离线单页和 ZIP 归档。

## 五、 暗房与大模型指令协同

在镜像暗房（Studio）中，Curio Box 支持通过大模型上下文与 `act` 指令对工件标签进行原子化版本追踪：

### 1. 一键复制提示词上下文
在暗房中点击“复制大模型提示词上下文”，工件已有标签、全局研判备忘与源码将自动构造成符合提示词工程的标准模板。

### 2. 大模型追加标签指令 (`add_tag`)
```act
add_tag
```
```
形态:webgl 物理:粒子 领域:图形学
```

### 3. 大模型移除标签指令 (`remove_tag`)
```act
remove_tag
```
```
状态:新建
```

暗房在预演模拟时，会自动呈现标签的增删 Diff 审查，并在确认落盘后自动计入工件的历史提交快照中。
